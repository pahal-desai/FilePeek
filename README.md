# FilePeek

I made this because I wanted to look inside files without opening 500 different apps.

## What it does

Drop a file in.

It can show things like:
- file information
- hashes
- hex
- metadata
- images
- PDFs
- audio
- video
- archives
- JSON
- CSV
- text
- and other stuff

It can also edit some files and convert some formats.

## How to use

Open it in a browser.

Drop a file.

Look at the file.

Edit stuff like hex and all

get the data uri, base64, or hex, of the file

That's basically it.

## Privacy

Files are processed in the browser.
